SEMANA 3

Pra relembrar:

* Imagem = molde do container
* Container = instância em execução da imagem
* PostgreSQL é um serviço separado da aplicação, diferente do sqlite que é só um arquivo
* DATABASE_URL permitiu trocar sqlite por postgresql sem alterar API, service ou repository (delícia de arquitetura)
* Variáveis passadas com -e viram env vars dentro do container
* docker exec permite executar comandos dentro de um container já rodando
* psql é o cliente de terminal do postgresql
* \dt lista as tabelas do banco
* \d nome_tabela mostra a estrutura da tabela
* reviews_db=# indica que estou dentro do postgresql
* Dockerfile descreve como construir uma imagem
* docker build gera uma imagem
* docker run cria um container a partir da imagem
* .dockerignore impede de subir junk pro pra imagem
* Docker Compose orquestra múltiplos containers! (belo)
* localhost dentro do container != localhost da máquina
* depends_on controla ordem de inicialização
