Pra relembrar:
* .venv é o virtual enviroment do python pra não instalar as dependencias globalmente
* deve ser criado via linha de comando no terminal
* requirements é equivalente ao package.json do node
* separei as responsas seguindo a lógica:
  - api pras rotas
  - schemas pra validação de dados/contratos
  - service pra lógica da aplicação (regras de negocio)
  - core pras configs (vai ter coisa no futuro)
